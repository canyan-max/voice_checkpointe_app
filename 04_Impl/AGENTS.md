# MCU Impl 层规则

本目录实现 `03_Platform/mcu_interface`，同时继承仓库根目录 `AGENTS.md`。

- 允许依赖目标 MCU 厂商库、生成配置和 `00_Project_Config` 的物理绑定，但禁止依赖 App、Service 或具体业务设备。
- 每个实现必须校验逻辑资源 ID 和映射表边界，再访问实际外设。
- 中断/DMA 回调只搬运必要数据和发布通用事件，不在 ISR 中执行日志格式化、协议解析或业务状态机。
- UART、I2S、GPIO 等实现对上只返回 `platform_err_t` 和平台通用类型，不向接口层泄漏厂商返回值。
- 修改时优先适配已有厂商初始化结果，不重复初始化同一外设；发现生成配置不符时先核对工程事实。
- 涉及缓存、DMA 和并发访问时必须说明所有权、有效期、对齐要求和临界区策略。
