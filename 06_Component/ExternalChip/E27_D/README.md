# E27-D 驱动

依据《E27-D AT指令手册 V1.0.1》实现当前工程所需的协议子集。
章节：1.1、1.2.1～1.2.4、1.2.7～1.2.8、1.2.13～1.2.15、
1.3.1～1.3.2、1.9.1～1.9.2、1.10.2～1.10.3、1.13、1.14.2。

## 职责与使用顺序

- 驱动负责命令编码、参数校验、回包解析和单条命令状态。
- BSP 注入发送和事件回调；同一 UART 由一个调用者串行管理。
- 上层安排配置步骤、目标地址、注册包、重试和供电时序。
- `e27_d_device_t` 必须先零初始化，调用者持有并管理其整个生命周期。
- `init` 只装配回调，不发送命令、不操作电源。活动命令或回调执行期间不能重新初始化。
- `command_start` 有限时发送，后续通过 `response_process` 消费接收数据，周期调用 `tick` 检查超时。
- 时钟为同一来源的 `uint32_t` 毫秒计数，允许回绕，调用间隔应小于半个计数周期。
- 一条命令结束且当前接收块全部处理后，才能发送下一条命令。
  尚未收完的行会使新请求返回 BUSY，避免丢掉半条异步通知。
- 所有回调内禁止重入驱动 API；回调应立即复制需要保留的事件内容。

## 命令与响应

- `+++` 恰好三个字节；其他命令追加 `\r\n`。
- `CPIN`、`GSN`、`ICCID`、`IMSI`、`CSQ` 不带问号。
- 支持模式、Modbus 转换、HEX 转换、注册包、心跳包、服务器、
  副服务器、状态上报及自动退出时间设置，以及保存、重启、身份和诊断查询。
- ASCII 注册包/心跳包最多 128 字节，HEX 最多 256 个字符，必须为偶数个十六进制字符。
  输入不要求 NUL 结尾；拒绝引号、控制字符，避免命令注入。
- 驱动不限制注册包为 16 字节，16 字节 ID 是本项目业务约束。
- `+ASKCONNECT: A,B` 是两个通道的连接状态，并非“通道号、状态”。
- 身份、信号、连接查询及 DTUID 回包转换为类型明确的事件。
  其他已收全的文本行通过 LINE 事件上报，供后续扩充解析。
- 查询数据在 COMPLETE/OK 前只是临时结果。失败时上层必须丢弃这次查询结果。
- 每块接收数据完整消费，OK/ERROR 后的异步通知不会因切换命令而丢失。
- 所有命令都必须收到 OK。活动命令收到 `AT Ready` 而尚未收到 OK 时以 RESET 结束，
  重启指令也不例外。重启的 OK 确认指令被接受，后续 READY 才确认实际启动。

## 时序与恢复边界

手册没有规定命令回复的最大等待时间，发送/回复超时由上层明确提供，
范围为 1～INT32_MAX 毫秒；回复预算包含发送耗时且不能短于发送预算。
不添加手册未要求的 `+++` 前后静默间隔。

模式是最近确认的状态。AUTOATO 持久配置未知时，驱动使用手册允许的
最短非零时长 60 秒作为保守失效期限，而非假定模块保持出厂的 120 秒。
上层应在确认启动后进入配置模式，并尽早显式设置 AUTOATO，建立确定的时序。
重复 `+++` 不被假定为重新开始自动退出计时；仅查询不能证明计时重新开始。
已处于模式未知状态的旧会话不能凭驱动计时推断模块实际自动退出时刻。

ERROR、超时、发送失败、接收丢失或活动命令收到超长/非文本行会使模式未知。
没有活动命令时，非文本数据只使文本观察器丢弃当前行，不改变透传模式。
驱动不自动重试，不自动发送 ATO。上层应先停止业务发送、处理或丢弃
传输层滞留数据，再重新进入命令模式，或根据业务需要执行复位恢复。
AT 协议没有请求序号，无法区分迟到 OK 与新命令的 OK，因此禁止在未排除
旧回复时直接发起下一条命令。

当前 BSP 保留原始接收字节，并并行观察启动和连接状态文本；普通数据没有
活动命令时不会被当作命令结果。尚未定义业务协议，后续协议需要规定控制文本
与业务内容的分流规则，或调整状态上报方式，避免串口内控制文本与业务内容碰撞。

`AT+MQTTSSL=0,1` 不在本版手册中，但用户确认旧板测流程可用；
保留这一条已验证的固定命令，不扩展未知参数。`AT+ASKNET?` 未纳入新流程。
MQTT/HTTP/其他工作模式的通知当前通过 LINE 返回，后续按需求增加类型映射。

## 内存与验证

调用者持有固定 context，内部含 384 字节行缓存，不创建 RX FIFO、不分配堆内存。
单次发送使用 320 字节栈缓冲，容纳最大 HEX 包及命令封装。
已由 BSP 绑定驱动，由独立 App 任务调用；任务初始栈为 1024 words，
运行时每 10 秒报告高水位。实测栈余量仍需在板上确认。

主机测试文件 `tests/test_e27_d.c`，不纳入嵌入式工程。
使用 GCC：

```text
gcc -std=c11 -Wall -Wextra -Werror -pedantic e27_d.c tests/test_e27_d.c -o test_e27_d.exe
test_e27_d.exe
```

覆盖编码/参数边界、各字节断点分段、同块终止回复与通知、两通道结果、
重启、错误、溢出恢复、忙状态、回调重入、时钟回绕及传输失败。
