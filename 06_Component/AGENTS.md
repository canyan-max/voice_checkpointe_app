# Component 层规则

本目录保存可复用组件和具体外挂芯片驱动，同时继承仓库根目录 `AGENTS.md`。

- 自研 Component 禁止依赖 App、Service、BSP、板级资源 ID、FreeRTOS 和 AT32 厂商库。
- 硬件访问通过初始化时注入的回调与可选 `p_context` 完成；组件不直接选择 UART、GPIO、I2S 或定时器实例。
- `ExternalChip/<型号>` 内可以使用芯片型号、寄存器、命令字、私有事件和状态，但这些类型不得越过 BSP 公共边界。
- 驱动负责帧格式、参数校验和芯片状态，不负责板级音频互斥、任务调度或应用重试策略。
- 所有长度、数组边界、帧间时序和等待超时都必须依据器件手册校验；禁止依赖调用者“保证正确”。
- 上游第三方组件原则上不修改；确需修改时先征得用户同意，并把适配限制在独立端口文件或最小补丁中。
