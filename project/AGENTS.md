# Project 装配层规则

本目录包含厂商生成工程、启动配置和 FreeRTOS 任务装配，同时继承仓库根目录 `AGENTS.md`。

- 厂商生成的 `.c/.h` 优先只修改 user code 区，禁止改变生成器维护的结构和标记。
- `freertos_app.c` 负责创建系统任务及临时板上验证入口；业务处理应调用 App 接口，不得直接调用 BSP、平台 UART 或 ExternalChip 驱动。
- `start_or_test_f` 当前保留用于 KEY1/KEY2/KEY3 板上触发验证，但测试逻辑不得复制正式播放器状态机。
- 外设引脚、DMA、时钟和中断配置以生成工程和资源表核对结果为准，不凭其他项目的配置直接移植。
- 修改 `.uvprojx` 时只增删需求涉及的文件、分组和包含路径，并确认通配工程脚本仍能定位该工程。
- 代码或工程配置修改后执行完整 Keil 编译并要求 0 error、0 warning；仅文档变化无需编译。
