# Project Config 层规则

本目录只描述逻辑资源编号与目标板物理资源绑定，同时继承仓库根目录 `AGENTS.md`。

- `board_resources.h` 只定义稳定的逻辑资源 ID，不包含 MCU 寄存器、任务状态或具体业务流程。
- `board_at32f435_binding.h` 只把逻辑资源映射到 AT32 工程生成的端口、引脚、外设和 DMA 实例。
- App、Service 和 Component 只能使用逻辑资源或其所在层的通用接口，不得直接使用本目录中的物理绑定宏。
- 修改绑定前必须同时核对原理图、资源分配表和 `project/inc/at32f435_437_wk_config.h`；三者冲突时停止并向用户确认。
- 新增资源时必须同步检查资源数量、配置表边界以及实现层映射表，禁止留下只声明未绑定的条目。
