# cat5171tbi-00gt3芯片部分使用知识

## 1.本机硬件原理配置

## 1.1 通讯方式

* I2C
* ID：7位 0b0101100X

## 1.2 硬件接线方式

* A脚链接前端输入运算放大器
* W连接音频AMP的音频输出
* B连接AMP_REF
* AD0连接GND
* SCL和SDA连接MCU的SCL和SDA
* VDD接3.3V
* cat5171tbi-00gt3器件阻值大小是100kΩ

## 1.3 调节电阻计算公式

因为我们是调节W引脚和B引脚之间的关系所以使用以下公式,调节A和W引脚之间的关系以下公式则不适用

~~~
RWB  = D/256*RAB+RW
RW 	 = 50Ω
~~~
